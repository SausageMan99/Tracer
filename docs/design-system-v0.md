# TrailForge — Design System V0

## Direction

TrailForge doit être perçu comme un instrument cartographique sensible, pas comme un SaaS IA ou une application performance. La carte est le personnage principal : elle lit le terrain, laisse émerger une boucle, puis seulement après expose les métriques utiles.

Phrase de marque : **Laisse le terrain dessiner ta sortie.**

## Principes

- La carte avant le dashboard.
- L’envie de sortie avant les métriques.
- Le GPX comme preuve, pas comme hero.
- Une imperfection maîtrisée : grain, courbes, annotations, micro-décalages.
- Une seule animation signature : la boucle qui apparaît comme révélée par le terrain.
- Refus honnête plutôt que trace mensongère.

## Typographie

- Titres : Fraunces
- UI / texte : Instrument Sans
- Données / coordonnées / GPX : IBM Plex Mono

## Logo

Wordmark sobre + monogramme cartographique. Le symbole actuel est une boucle organique posée sur des courbes de niveau. Il doit pouvoir vivre comme un tampon de carte, pas comme une icône SaaS.

## UI

Le générateur est un panneau de préparation de sortie : départ, distance, D+, ambiance, préférence terrain. Le CTA principal est **Dessiner la boucle**.

Le résultat doit donner envie de sortir : nom/état de la boucle, carte lisible, GPX visible, fiabilité honnête, explication du tracé.

## Anti-patterns

- “AI-powered route generation”
- smartphone hero
- cards SaaS arrondies partout
- dashboard rempli de chiffres dès l’arrivée
- photos stock de runners
- promesse de route parfaite
